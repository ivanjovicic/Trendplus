# RQ276 — Separate Inventory expected impact from exposure/value

## Interpreted outcome
Inventory central-action writes must not present stock exposure (`estimatedValue`) as expected business impact (`impactEstimateRsd` / `expectedImpactRsd`).

## Owner
Frontend inventory actions (`InventoryPage`, `inventoryUtils`, `ActionWorkflowPanel`).

## Contract handoff note
Backend `InventoryActionSuggestionDto` exposes `EstimatedValue` only and no authoritative expected-impact field. Backend workflow values represent current-stock exposure, while locally generated forecast values represent suggested-action cost; frontend omits impact fields and records these under distinct metadata bases.
