## Interpreted Outcome and Owner

**Owner**: Analytics Frontend / Inventory  
**Outcome**: Confirmed and documented the product contract: Inventory balance KPIs (total SKU, on-hand, low-stock, average, value) are computed for **whole inventory scope**, not filtered by SKU search. Updated KPI card notes with explicit scope documentation to prevent user confusion.

## Working Hypothesis

Balance KPIs are intentionally computed without search filtering, representing authoritative whole-scope metrics. The list table and insights are filtered by SKU search. This separation needed clearer UI documentation.

**Hypothesis verified by**:
- Backend API inspection: `GET /balance` calls `ApplyInventoryFilters(..., null)` for search parameter
- Frontend API call inspection: `getInventoryBalance()` not passed `search` parameter
- Product intent: KPIs serve as global context, not filtered subset
