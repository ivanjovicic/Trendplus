## Outcome

Daily Sales now preserves unknown, missing, insufficient, `NaN` and `Infinity` values as unavailable instead of converting them to trusted zero. Valid measured zero remains zero. Zero-denominator ratios, empty rolling windows, incomplete windows, anomaly deviations, concentration shares, summary values and chart tooltip values stay unavailable when the evidence is not valid.

The API client uses additive nullable numeric DTO types for runtime partial payloads. No backend formula, recommendation, confidence, cache, refresh or SQL behavior was changed.
