## Finding

- `TrendplusDbContext` maps `ProdajaStavka.PurchaseCostProvenance` to `prodaja_stavke.purchase_cost_provenance`.
- The field is queried by Supplier, Shoe Type and Color sales, as well as Insight Studio, Supplier Decision Hub, detail/cost snapshot and data-quality readers. The same absent column can therefore fail several analytics screens.
- The EF migration `20261010160000_AddPurchaseCostProvenance` and full core bootstrap already add the nullable column. However, `EnsureTrendplusCoreSchemaAsync` skips the full bootstrap when core tables are present. If migration history is ahead of the physical schema, `MigrateAsync` skips the already-recorded migration and previously allowed initialization to complete.
- The supplied incident proves PostgreSQL `42703` in Shoe Type, but does not show the production database migration history. That exact remote state is unverified.
