# RQ272 Evidence Log

**Date**: 2026-09-15  
**Task**: Prevent Inventory page rows from masquerading as total value  
**Status**: DONE  
**Run Evidence**: This document

## Interpreted Outcome and Owner

**Owner**: Analytics Frontend / Inventory  
**Outcome**: Removed fallback logic that summed current page rows as total inventory value when backend total was unavailable. Now uses only authoritative backend `balance.estimatedInventoryValue`. Unavailable totals render as "-" rather than silently presenting page sums.

## Working Hypothesis

When `balance.estimatedInventoryValue` is null (backend unavailable), the current code sums page `rows` and displays it as total. With pagination, this false total changes when users page to different SKUs.

**Hypothesis verified by**:
- Code inspection: Line 701 fallback logic confirmed
- Risk analysis: Page sum can differ significantly from true total with pagination
- Solution: Remove fallback; only use authoritative backend value
