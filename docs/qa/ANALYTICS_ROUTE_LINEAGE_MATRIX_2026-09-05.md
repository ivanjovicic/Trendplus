## Reading rules

- `CONFIRMED-STATIC` means the current repository contains the referenced route, client, endpoint, DTO, query/source or test declaration.
- `UNPROVEN-RUNTIME` means the repository inspection cannot prove the deployed response, database relation, applied migration, cache contents, worker registration, refresh success or browser behavior.
- `UNKNOWN` is the correct value for a trust field when no source contract or runtime evidence was found. It must not be rendered as zero, fresh, healthy or actionable.
- A source path with a line number is a static confirmation basis, not a claim that the line executed successfully.

## Static completeness and proof boundary

- Completeness is mechanically checked by `scripts/check-analytics-lineage-matrix.mjs`.
- The checker validates required routes/families and every trust-field heading; it does not validate a database, deployment or browser.
- No row in this document proves an endpoint returned 200, a table/view/migration exists in the current database, a worker ran successfully, or a browser emitted no console warning/error.
- The matrix is therefore suitable for selecting the next runtime/parity prompt, not for marking analytics production-safe.
